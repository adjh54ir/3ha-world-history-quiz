### 카테고리

**왜 교육이 아니라 게임 > 퀴즈인가** (2026-10-14 한국 App Store 무료 차트 조회 결과)

- **경쟁 앱이 전부 게임에 있음** — `세계 수도 퀴즈 · 두뇌게임`(평가 411), `세계사 퀴즈 - 역사 게임`(133), `한국사 퀴즈`(19,048), `OX퀴즈 서바이벌 100`(8,414) 모두 게임. "연관 앱" 노출을 같이 탑니다.
- **퀴즈 차트는 진입 장벽이 낮음** — 퀴즈 무료 TOP 100 의 71위가 평가 210개짜리 국기·수도 앱입니다. 이 앱과 같은 장르가 차트 안에 실제로 있습니다.
- **교육 차트는 대형 서비스 독점** — 1~10위가 듀오링고·말해보카·오르조·운전면허 앱, 하위권도 학교·기관 앱이라 상식 퀴즈가 들어갈 자리가 없습니다.
- 앱 구조(타임챌린지 랭킹·주간 리그·타워 보스·배지 85개)가 게임 루프라 리뷰어 분류와도 맞습니다.

> 참고: App Store **게임** 카테고리 앱은 중국 본토에 판매하려면 게임 판호(ISBN)가 필요합니다. "모든 지역" 을 선택해도 중국 본토는 판호(또는 ICP 비안) 없이는 심사가 막히므로, **가격 및 사용 가능 여부에서 중국 본토만 해제**하세요. 한국어 전용 앱이라 영향은 없습니다.

## 10. "유효하지 않은 문자" 오류 예방 규칙

App Store Connect 가 `필드에 하나 이상의 유효하지 않은 문자가 포함되어 있습니다` 를 띄우는 원인입니다.
**§4 · §5 의 복사용 박스 값은 아래 규칙을 지켜 작성했고, 이모지·특수 기호 검사를 통과했습니다.**

| 쓰면 안 되는 것 | 이유 |
|---|---|
| 이모지 (🌍 ✈️ ✅ 등) | 이름·부제·키워드·프로모션 텍스트에서 즉시 거부. 설명에서도 반려 사례 다수 |
| 특수 기호 ™ ® ★ ✓ ■ ● ▶ 와 긴 대시 – — | 유효하지 않은 문자로 잡힙니다 |
| 전각 공백 (U+3000) · 줄바꿈 없는 공백 (U+00A0) | 눈에 보이지 않아 원인 찾기가 어렵습니다 |
| 스마트 따옴표 “ ” ‘ ’ | 편집기 자동 변환 주의. 이 문서는 곧은 따옴표 `"` 만 씁니다 |
| 키워드 필드의 공백 | 쉼표 뒤 공백도 글자 수에 포함됩니다 |

써도 되는 것: 한글, 영문, 숫자, 줄바꿈, `. , : ; ( ) [ ] - / · % + ~ ! ? "`

붙여 넣은 뒤 오류가 나면 아래 명령으로 문제 문자를 찾을 수 있습니다:

```bash
python3 -c "
import sys,unicodedata
s=open('/tmp/desc.txt',encoding='utf-8').read()
for i,ch in enumerate(s):
    if unicodedata.category(ch) in ('So','Sk','Cf','Zs') and ch!=' ' or ord(ch)>0xFFFF:
        print(i, repr(ch), hex(ord(ch)), unicodedata.name(ch,'?'))
"
```
