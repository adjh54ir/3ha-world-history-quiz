## 왜 두 벌인가

기본 자료(`hanja-strokes/`, Make Me a Hanzi)는 중국 자형이라 한국에서 쓰는 글자가 없다.
그래서 姉·飮·絶·鑛·眞 같은 27자가 비슷한 다른 글자로 그려지고 있었다.
그 27자와, 자료가 아예 없던 瘍·垈·僞, 참조 표에만 있던 憺·顚·蹐 을 여기서 제 모양으로 그린다.

두 자료에 같은 글자가 있으면 `ConstHanjaStrokes.ts` 의 `selectStrokes` 가 **이쪽을 먼저** 쓴다.

아직 두 자료 어디에도 없어 비슷한 글자로 그리는 이체자 7자: 淸 鄕 敎 硏 卽 郞 槪

## 자료 모양

```
{ "姉": [ [[x,y],[x,y],…],  … ] }   // 글자 → 획마다의 점열 (쓰는 순서)
```

- 좌표계 **109×109**, y 축이 아래를 향한다 — 바깥선 자료(1024×1024, y 축 위)와 다르다.
  뒤집는 변환이 필요 없어 `transform` 을 주지 않는다.
- 획 **바깥선이 없다.** 중심선 하나뿐이라 화면에서는 굵은 선으로 긋는다
  (`HanjaStrokeCanvas` 의 `mode === 'line'` 갈래).
- 원자료는 SVG 3차 베지에 곡선이다. 화면에서 획 길이를 재야 해서 만들 때 점열로 잘라 두었다
  (곡선 길이 3 단위마다 한 점, 획마다 3~16점).

## 다시 만드는 법

1. [KanjiVG 배포본](https://github.com/KanjiVG/kanjivg/releases) 의 `kanjivg-<날짜>-main.zip` 을 풀어 `kanji` 폴더를 얻는다.
2. 글자마다 `kanji/<코드포인트 5자리 소문자 16진>.svg` 에서 `id="kvg:…-sN"` 인 `<path>` 의 `d` 를 순서대로 읽는다.
   (획순 번호를 그리는 `<text>` 는 건너뛴다)
3. `d` 의 곡선을 점열로 잘라 위 모양으로 담는다.
