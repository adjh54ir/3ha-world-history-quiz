# 상점·코스튬 에셋 제작 프롬프트

내장 `imagegen`으로 제작했다. 공통 기준은 기존 팬더의 잉크·수채화 질감, 또렷한 외곽선, 주황·금색·민트·남색 계열, 정사각형 중앙 배치, 실제 알파 투명 배경이다. 코스튬에는 팬더나 마네킹을 넣지 않고 착용 아이템 하나만 그렸다.

## 코스튬 8종

- `flower`: 금빛 꽃술과 작은 잎이 있는 연분홍 매화 머리 장식
- `ribbon`: 금색 테두리가 있는 주황빛 목 리본
- `glasses`: 투명 렌즈와 가는 금테의 둥근 학자 안경
- `tophat`: 주황 띠와 금색 버클이 있는 검은 실크햇
- `sunglasses`: 호박색 반사 렌즈의 검은 선글라스
- `scarf`: 금색 스티치가 있는 민트색 목도리
- `gradcap`: 주황 테두리와 금색 술이 있는 남색 학사모
- `crown`: 붉은색·민트색 보석이 박힌 금빛 왕관

## 상점 소모품 3종

- `shield`: 불꽃 문양과 주황 리본이 있는 스트릭 보호 방패
- `snack`: 대나무 잎 포장과 주황 리본으로 묶은 팬더 간식
- `chest-key`: 붉은색·남색·금색 보물상자와 금빛 열쇠 한 세트

## 추가 상점 아이템 3종

- `focus-charm`: 다음 퀴즈 보상 부적. 붉은 한지 패찰에 먹글씨 `集`, 금색 문양, 민트 술 장식
- `review-brush`: 오래된 오답을 정리하는 대나무 붓. 흰 붓끝이 번진 먹 자국을 쓸어 내리는 모습
- `study-scroll`: 펫 경험치를 올리는 학습 두루마리. 대나무 무늬 한지에 먹글씨 `學`, 금색 축과 민트·주황 매듭

세 이미지 모두 `stylized-concept` 용도의 모바일 상점 아이콘으로 요청했으며, 중앙의 단일 오브젝트, 생활 한자 앱의 먹선·수채화 질감, 실제 알파 투명 배경, 로고·워터마크·추가 문구 없음 조건을 공통 적용했다.

## 상점 확장 아이템 10종

- `bamboo-lunch`: 대나무 잎 주먹밥이 담긴 짜임 도시락
- `master-inkstone`: 먹물이 소용돌이치는 금색·옥 장식 검은 벼루, `文` 각인
- `review-broom`: 종이 조각과 먹 자국을 쓸어 내는 대나무 책상 빗자루
- `wrong-shield`: 먹글씨 `正`이 들어간 남색·옥색 원형 방패
- `chest-seal`: 금빛 먹글씨 `寶`가 새겨진 붉은 보물 인장
- `learning-bookmark`: 먹글씨 `學`과 대나무 그림이 있는 옥 장식 책갈피
- `attendance-incense`: 금빛 `日` 문양이 있는 남색 향로
- `treasure-map`: 산수화 위에 상자까지 가는 길이 표시된 두루마리 지도
- `golden-key`: 옥 장식과 붉은 술이 달린 구름무늬 황금 열쇠
- `costume-bundle`: 왕관·학사모·안경·꽃 장식이 담긴 남색 비단 보따리
  - 2026-09-14 삭제 — `costume-*.webp` 18장과 `item-costume-bundle`·`item-silk-wardrobe` 는 코드에서 쓰는 곳이 없어 걷어냈다.
    프롬프트는 다시 그릴 때를 위해 남겨 둔다 (그림 파일은 없다).

공통 프롬프트는 `stylized-concept`, 512px 상점 카드에서 읽히는 단일 실루엣, 한국풍 먹선·수채화, 남색·옥색·주황·금색 팔레트, 실제 알파 투명 배경, 인물·팬더·로고·워터마크 없음으로 지정했다.

## 추가 상점 아이템 3종

- `focus-charm`: 먹글씨 `集`이 적힌 붉은색·금색 집중 부적과 민트색 술
- `review-brush`: 흐려지는 먹자국을 쓸어 내는 대나무 손잡이 복습 정리 붓
- `study-scroll`: 먹글씨 `學`이 적힌 한지 두루마리와 옥 장식

## 상점 콘텐츠 확장 10종

- `moon-tea`: 달빛 증기와 대나무 잎이 있는 청자 찻잔
- `memory-orb`: 먹자국 종이가 흐려지는 옥빛 기억 구슬
- `scholar-elixir`: 금빛 비약이 든 남색 유리병과 옥 마개
- `treasure-compass`: 보물상자 세 개를 가리키는 구름무늬 나침반
- `silk-wardrobe`: 머리띠·외알 안경·노리개가 든 남색 비단 옷장
- `bamboo-pin`: 세 장의 옥빛 대나무 잎과 금색 매듭 비녀
- `scholar-band`: 금색 구름 장식과 주황 끈이 있는 남색 학자 머리띠
- `monocle`: 옥 구슬과 짧은 체인이 달린 금테 외알 안경
- `jade-pendant`: 남색 끈과 주황 술이 있는 옥 노리개
- `cloud-collar`: 옥빛 구름 자수와 주황 끝단의 남색 비단 깃

내장 `imagegen`의 `stylized-concept` 용도로 제작했다. 모든 이미지는 512×512 RGBA PNG이며, 한국풍 먹선·수채화 질감, 남색·옥색·주황·금색 팔레트, 실제 알파 투명 배경, 로고·워터마크 없음을 공통 조건으로 적용했다.

## 상점 탭 확장 10종

- `guardian-crate`: 대나무 잎으로 싼 옥빛 먹이 세 개가 든 남색 양식 상자
- `study-toolkit`: 부적·책갈피·방패·붓이 정리된 학습 도구함
- `attendance-kit`: 보호 방패와 옥빛 향로가 든 출석 준비함
- `review-brazier`: 오답 종이를 태우는 남색·옥색 장식 화로
- `five-color-chest`: 오색 구름무늬와 옥 장식의 황금 보물함
- `plum-hairpin`: 산호빛 매화 세 송이와 옥빛 잎의 금장 비녀
- `tiger-ears`: 남색 비단띠에 연결된 주황빛 호랑이 귀
- `ink-mustache`: 가운데 금장식으로 연결된 대칭 먹선 수염
- `scholar-mask`: 옥빛 틀과 남색 구름 장식의 선비 반가면
- `guardian-bell`: 남색 끌·옥 구슬·주황 술이 있는 금빛 수호 방울

내장 `imagegen`으로 각 에셋을 별도 생성했다. 기능형은 단일 상품 실루엣, 코스튬은 슬롯별 착용 오버레이로 요청했고 512×512 알파 PNG로 축소했다.

## 만들어야 하는 에셋 1종

- `pet-feed`: 출석 수호신(청룡) 먹이. 옥빛 여의주와 대나무 잎을 얹은 작은 먹이 그릇 — 남색·옥색 바탕에 금색 테두리

아직 그리지 않아 상점 줄과 보유 아이템 칩은 임시로 `illustrations/azure-dragon-stage-1.png`(신수알)을
아이콘으로 쓴다. 위 프롬프트로 `item-pet-feed.png` 를 만들어 `SHOP_ITEM_IMAGES.petFeed` 로 추가하면
`LifeShopScreen` 의 `petFeed` 줄과 `inventory` 항목에서 `ATTENDANCE_PET_IMAGES[0]` 만 바꿔 주면 된다.

## 반복 구매 영구 강화 5종

- `engraving-inkstone`: 검은 먹물이 담긴 금색 구름무늬 벼루, 옥 장식과 다섯 단계의 금빛 성장 고리
- `answer-abacus`: 남색 나무틀과 금장 모서리, 옥색·주황색 알과 다섯 개의 금빛 단계 표식이 있는 주판
- `attendance-lantern`: 따뜻한 주황빛을 내는 남색 전통 등불, 금색 꽃장식과 옥색 매듭·술
- `treasure-loupe`: 엽전과 보물 기호를 비추는 금장 확대경, 옥 손잡이와 다섯 개의 성장 표식
- `guardian-bowl`: 금색 구름 테두리의 옥빛 밥그릇, 대나무 잎과 빛나는 옥 구슬 먹이, 다섯 개의 금빛 표식

내장 `imagegen`의 `stylized-concept` 모드로 각각 별도 생성했다. 모바일 상점 카드용 중앙 단일 오브젝트, 한국풍 먹선·수채화 질감, 남색·옥색·주황·금색 팔레트, 실제 알파 투명 배경, 인물·팬더·로고·워터마크·불필요한 문구 없음 조건을 공통 적용했고 512×512 RGBA PNG로 저장했다.

## 게임형 상점·완료 화면 에셋

- `shop-pavilion-hero`: 남색 목조 선반에 두루마리·벼루·옥 장식·보물함·비단 상자가 진열된 한국 판타지 상점. UI 문구가 놓일 중앙 왼쪽은 비우고 하단에는 따뜻한 목재 계산대를 둔 3:1 가로 배경
- `today-quiz-complete`: 흰 붓 획 체크가 있는 금빛 합격 인장, 옥빛 정답 패 다섯 장과 주황 리본으로 구성한 완료 엠블럼

내장 `imagegen`의 `stylized-concept` 모드로 별도 생성했다. 상점 배경은 1536×512 불투명 PNG, 완료 엠블럼은 512×512 알파 PNG로 저장했다. 공통 팔레트는 남색·옥색·주황·금색이며 보라색, 인물, 팬더, 로고, 워터마크, 불필요한 글자를 제외했다.
