# 나침반 올빼미 성장 에셋

내장 ImageGen으로 제작한 512×512 투명 WebP 에셋이다. 세계사 탐험 분위기의 크림·청록·남색·금색 팔레트와 굵은 먹선, 셀 셰이딩, 잔잔한 스크린프린트 질감을 공통으로 사용한다.

| 파일 | 성장 단계 |
|---|---|
| `world-owl-stage-1.webp` | 나침반 문양이 새겨진 잠든 알 |
| `world-owl-stage-2.webp` | 알을 깨고 나온 올빼미 새끼 |
| `world-owl-stage-3.webp` | 나침반 목걸이를 단 꼬마 탐험올빼미 |
| `world-owl-stage-4.webp` | 비행모·지도 배낭을 갖춘 지도날개 올빼미 |
| `world-owl-stage-5.webp` | 세계지도 날개와 남색 망토를 갖춘 수호 올빼미 |
| `world-owl-stage-6-golden.webp` | 황금 나침반 후광과 펼친 날개의 최종 진화 |

공통 프롬프트: 승인된 6단계 시트를 정체성 기준으로 사용한다. 같은 호박색 눈, 크림색 얼굴 원반, 청록색 깃털, 금색 나침반 표식을 유지하고 단계마다 실루엣과 장비만 성장시킨다. 한 캐릭터만 중앙에 배치하고 실제 투명 알파를 사용한다. 글자·숫자·국기·국가 상징·정치 및 종교 상징·배경·프레임·보라색·워터마크는 넣지 않는다.
