# 출석 보상 청룡 5단계

Built-in `imagegen`으로 제작한 512×512 투명 PNG 에셋이다. 현대적으로 정돈한 한국 민화 삽화, 무광 광물 안료, 마른 먹선, 청자색·짙은 먹남색·상아색·절제된 금빛·주홍 매듭을 공통 아트 디렉션으로 사용했다.

- 1일: 먹빛 신수알 — 상아색 알, 먹구름 붓결, 청록 비늘
- 7일: 깨어나는 용알 — 금이 간 알 안에서 뿔과 눈이 등장
- 14일: 묵룡 새끼 — 깨진 알에서 나와 작은 붓을 품은 아기 청룡
- 21일: 필법 청룡 — 몸이 길어지고 붓과 빈 두루마리를 갖춘 수련생 청룡
- 28일: 천자 청룡 — 완전히 성장해 먹빛 원환과 큰 붓을 갖춘 서예 수호신

공통 제약: 단계마다 같은 개체와 화풍, 가운데 배치된 단일 캐릭터, 실제 투명 알파, 글자·풍경 배경·프레임·보라색·3D 광택·게임 아이콘 렌더링 없음.
